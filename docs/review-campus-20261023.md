# 1.6.1 校招表单审查与实测

基线：upstream main `aa3032b`。工作分支：`fix/campus-form-safety`。

## 已修复

- **隐私边界**：网页能访问开放的 Shadow DOM；原悬浮按钮接受合成点击，可被网页脚本触发本地简历读取。按钮现只接受 `isTrusted` 用户事件；公开 DOM 诊断仅保留计数、字段键、状态和原因代码，移除原始资料值。
- **AI 信任边界**：默认白名单模式拒绝模型生成正文、无本地来源的字段值和是非答案；拒绝未知键、原型键、缺失/非有限/低置信度。全文模式需显式开启；开放题生成保留在明确的文本控件中。应用映射时重新检查字段标签、索引、置信度和禁填语境，降低表单变化后按旧索引错写的风险。
- **字段语义**：可读标签优先于 ATS 属性名；修复证件号码被 `certificateNo` 抢成证书、项目职务被“名称”抢成项目名、GitHub 星级被当作链接、英语成绩被当作等级、辅修被当作主修；家庭与亲友字段不会使用申请人姓名、公司和电话。
- **多段与加行**：识别 `resumeEmploymentInfo` 以及 Hotjob `.form-cell-inner` 行结构；已有记录按实际行数计数；语言分区按资料展开；全职记录不再在无实习数据时自动回落成实习。
- **选择与回读**：Hotjob 语言等级的嵌套“语种 → 等级”按顺序提交；Ant Design v3 选择后核对目标值；支持 CET-4/6 与四级/六级；数值 GPA 取分子；Phoenix 审计读取选中值一次，不重复拼接隐藏测量文本；毕业届次的“届”后缀不再误报。
- **缺口展示**：未填清单纳入自定义下拉，识别 Ant Design 必填标记；日历和字典弹层中的搜索输入不参与简历主循环。

## 验证

- Node 单元测试：211 项通过；简历解析：20 项通过。
- 字段匹配基准：265/265，错配 0、漏配 0。
- 在 ego-browser 中使用兼容适配器执行 DOM 用例，31 个不同用例最终通过，包括日期、下拉、联动、受控组件、校招字段与悬浮窗隐私回归。
- ego 后台页 `document.hasFocus()` 为 false，7 个依赖 focus 的用例首次失败；按浏览器技能使用页面 `FocusEvent` 适配后重跑通过。这验证事件处理与回写路径，不能据此宣称所有前台原生焦点行为已验证。
- 本机缺少 Playwright，`npm test` 自带的 Playwright DOM 子进程被跳过；未运行 `test:real` 的全部组件库矩阵。真实申请页另以隔离世界注入本次代码、读取本地资料进行填写与 UI 回读；这不等同于已安装新的扩展版本。
- `git diff --check`、修改脚本语法检查、打包引用完整性检查及敏感资料检查通过。未新增依赖。
