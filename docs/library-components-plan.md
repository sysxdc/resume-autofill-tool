# 本地资料与新组件改进

## 本批目标

1. 审计资料字段与列表映射，补齐保存缺口，区分学位/学历、语言考试/熟练程度，建立可备份的安全整理入口。
2. 统一多段条目与主字段的取值来源，拒绝从不相关证书或其他经历推断答案。
3. 扩展通用 ARIA 下拉、远程搜索与虚拟选项列表；归属明确的弹层只在本控件内查找候选。
4. 用独立组件夹具和真实扩展矩阵验证，发布后核对本地资料变更。

## 数据处理约束

- 自动处理仅限有依据的错误类型、兼容精度补全、完全重复记录、明确标为实习的分类和缺失结构补齐。
- 保留不同语义的近似字段：学位不等于学历、证书等级不等于熟练程度、户籍不等于现居地。
- 内容冲突不盲目覆盖；整理前保存完整本机备份，真实资料不进入仓库。
- 组件仅在目标选项已提交且回读匹配后计成功；禁用项、其他弹层选项、搜索词不算填写成功。

## 1.8.0 已实现

- 字段表无重复键，资料页无重复命名控件；补齐缺失的工作部门字段。兼容主条目与经历列表的重复值作为镜像保留，列表存在时主条目只读同步，不再双重编辑。
- 新增资料检查、备份整理与恢复；仅清理完整重复经历；相同分数的 GPA 可补全已知满分，学位被误写为学历时取已明确的学位；明确标为实习的工作条目迁移并保留更完整的职位。
- 语言证书与熟练程度分别保存；英语成绩/时间只允许回退到明确的英语证书。工作内容不再借用实习内容、业绩或求职意向。
- 手工保存同时维护实际档案与当前填写资料；列表删除后不会从旧主条目复活；保存途中新的表单编辑不被覆盖。
- 通用 ARIA 单选支持按钮/输入框、归属明确的 portal 弹层、远程等待和有滚动容器的虚拟列表，过滤禁用项并回读提交结果。
- 富文本仅插入纯文本，保持换行、保护已有内容，并检查组件拒绝写入；未提交搜索和富文本失败均有原因提示。

## 验证与边界

- 既有单元 211 项、字段安全与资料质量 9 组、解析 20 项；DOM 行为 37 项。新增资料整理/恢复、镜像保存/删除、远程/虚拟单选和富文本回归。
- 真实扩展矩阵新增通用 ARIA 与富文本两项，与既有 12 项一起验证内容脚本隔离环境。
- 既有匹配基准 265 条；只代表已标注的样本，不代表任意网站完全兼容。
- 通用 ARIA 适配本批支持单选 listbox；多选、tree/dialog 类型和无可靠关联关系的弹层仍明确留给人工或专门适配。
- 远程等待与虚拟滚动有预算上限；富文本按纯文本填写，不承诺保留复杂排版。
- 资料冲突保留待核对，不合并不同日期或不同内容的经历；真实资料及完整备份仅存于本机。
