# 1.8.0 实现复审

## 顺序与验收

1. 复现主字段被空经历字段或冲突值覆盖、无变更整理覆盖恢复点、恢复丢弃未保存编辑的问题。
2. 修复资料编辑/整理边界；合并实习记录时完整比较附加信息，无法确认同一段经历时保留两段。
3. 复现并修复 ARIA 搜索失败残留及异步期间覆盖用户输入；验证重试和提交回读。
4. 运行针对性回归、完整单元/DOM/解析测试、匹配基准和真实扩展矩阵，再复查差异和发布包。

不使用真实简历作测试数据。代码验证与用户浏览器中的升级、真实资料整理分别记录状态。

## 已修复（1.8.1）

| 严重度 | 可复现问题 | 修复与行为验证 |
| --- | --- | --- |
| 高 | 打开资料页后，经历空值/冲突值覆盖已有主字段，再保存会丢失原值 | 保留独立或冲突主值；明确编辑对应的第一条经历字段后再同步，编辑其他字段不隐式处理冲突 |
| 高 | 保存开始时未锁定，异步读取期间可切换档案 | 本页保存/整理/恢复/切换/导入/清空互斥，提交时立即取得快照；延迟读取用例验证另一档案未受影响 |
| 中 | 切换档案的 storage 回调未处理错误，活动 ID 与当前资料可能不一致 | 使用可拒绝的 Promise；切换写入失败时恢复原活动 ID，注入存储错误验证 |
| 高 | 实习合并把嵌套对象转为同一字符串，或仅凭同公司和缺失时间合并 | 完整比较附加数据；仅完全相同或公司和起止时间明确相同才尝试合并；保留真实冲突 |
| 中 | 连续整理无变更资料会覆盖原始恢复点 | 无变更时保留原备份，重复操作用例验证 |
| 高 | 恢复无条件覆盖未保存编辑，整理/恢复期间的新编辑也会被覆盖 | 未保存时拒绝执行；异步完成前比较表单快照，不覆盖新增编辑 |
| 中 | 下拉关闭后残留搜索词，被误判为选中，或下次重试被残留词挡住 | 要求选择标记/组件事件/选中值变化；失败撤回本次查询，原有或期间新增的用户输入保留 |

## 验证结果

- `node tests/run-tests.mjs`：211 项原有单元、10 项安全/资料测试、40 个 DOM 用例、20 项解析测试通过。
- `node tests/match-benchmark.mjs --check`：265/265，错配 0、漏配 0。
- `node tests/real/run-real.mjs`：14 个用例全部通过，覆盖通用 ARIA、富文本及现有组件矩阵。
- 原来的 `applyGen` 源码名称断言由真实的延迟保存/切换行为断言替代。

## 边界

- 本轮互斥保护作用于同一资料页；跨窗口并发编辑、进程终止时 IndexedDB 与 chrome.storage 的跨库原子恢复不在本轮保证范围。
- 通用 ARIA 不把单纯收起弹层视作提交；缺乏可观察选中证据的组件会保守留待核对，需要专门适配。
- 本轮没有操作五个真实网申页面，也没有应用真实资料整理或重新加载用户浏览器中的扩展。
