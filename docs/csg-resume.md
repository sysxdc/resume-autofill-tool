# 南方电网招聘简历适配

页面：`https://zhaopin.csg.cn/#/user-center/my-resume`

## 复现与原因

2026-10-24 使用 Ego 检查登录后的教育经历表单。页面采用按分区编辑的布局。

- 学校、学历和专业是 `.ant-cascader-picker`。旧逻辑跳过其中的搜索框，但没有收录该组件宿主。
- 学校中文和英文栏的 placeholder 相同，必须按标签区分。
- 教育上下文把「院校类型」判为学校，把「毕业人数」判为毕业时间。
- 个人绩点与满分绩点、名次与毕业人数共享一个标签，不能当作两段经历或写入同一个完整字符串。
- 无表单时曾提示「已填 0 项，没发现明显空缺」。

## 行为

- 级联搜索后只点击唯一匹配项，优先完全相符的叶子；核验已提交的选择标签，搜索词不计成功。
- 中文学校和 `schoolEnglish` 独立保存。缺少英文资料时留空。
- 拆分绩点和排名；缺少分母不推算。第一条教育记录的绩点分母可以使用同分子的主条目补足。
- 识别外语水平及其分数、等级和时间上下文。
- 旧版 Ant Select 优先走对应组件路径；按 `aria-controls` 绑定自己的菜单，菜单未挂载时不会借用其他字段的弹层。
- 语种、考试级别先于成绩填写，避免语种切换把已填成绩清空；CET-4 与大学英语四级等价，考试级别不使用语言熟练程度。
- Vue 2 日期按组件声明的 `valueFormat` 发出 change，经页面 v-model 更新后回读；隐藏模板不参与填写和记录计数。
- 南网的添加入口不按行数循环点击，用户打开分区后填写；确认、附件、声明勾选和最终提交仍由用户操作。

## 验证

`node tests/run-dom-tests.mjs csg` 覆盖：级联真实选中与回读、同名独立学院排除、英文学校隔离、分子分母、排名人数、拒绝未提交搜索、保留已有值以及不自动确认和提交。

2026-10-24 在 Ego 中加载 1.8.2，真实点击悬浮窗「一键填写」：教育与外语联合核验 **12/12 通过、0 错填、0 读回空值**。学校、学历、专业、起止日期、绩点、学位、学习形式、英语、四级和分数均按页面显示值核验。UI 将语种与等级作为一组计数，因此显示已填 11 项。学校英文名、排名、主修课程等缺失资料继续留空；附件、分区确认和最终提交由用户完成。测试没有验证服务器保存状态。

回归检查：211 项单元检查、42 项浏览器行为检查、20 项解析检查及 10 项资料与字段安全检查通过；265 条字段基准通过。所有夹具使用虚构数据，真实简历和现场记录不进入仓库。
