# 1.9.0 实施与验证记录

以 feat/library-components 当前工作区（含未提交的 1.8.2 南网适配）为基线。

## 实施顺序

1. 统一经历取值和 AI 语义映射，补齐教育行属性、考试成组取值和实习分类。
2. 保存使用字段补丁，保留未知数据；行编辑维护会话身份；增加学校英文名和显式多值入口。
3. 统一 DOM root / 控件身份，支持开放 Shadow DOM、多选，收紧弹层归属和联动等待。
4. 后台按 runId 调度 frame 并可信汇总；弹窗和悬浮窗使用同一入口。
5. 增补行为回归，收紧测试门禁，完整回归与复审后生成 1.9.0 包、提交推送和安装核验。

## 验收边界

- 默认 AI 请求仅传字段语义；具体值在本地按绑定记录取得。
- 已有内容保持；冲突、失效绑定、超时和不可访问 frame 明确待核对。
- 不新增生产依赖；不使用真实资料作为测试数据。
- 页面回读与服务器保存分别记录；不处理附件、声明或最终提交。
- 真实站点不能进入时如实记为未验证。

## 已实现

- `recordRef` 贯穿扫描、启发式、AI 映射及写入。主字段补全要求身份及起止日期同时一致；已有锚点冲突或记录歧义时跳过，写入前再次检查锚点。
- 列表资料展开为语义键目录，部分 AI 返回统一从完整字段集合回退。AI 给出的值不会覆盖本地来源；`index` 只保留作兼容信息。
- 教育行补齐院校类型、班级排名、专业人数；保存补丁保留未渲染字段，行会话身份随增删排序保留未知及嵌套附加数据。
- 英语名称、成绩、日期从同一记录取得；实习以明确性质优先，英文仅识别完整 `intern/internship`。
- DOM root、控件及 frame 分别标识。开放 Shadow DOM 使用同一扫描和空缺检查路径；桥接使用事件原始目标；同 ID 与同名 radio 按 root 隔离。
- 多选采用显式 `multiValues` 数组、空控件写入及集合审计。禁用选项和分组不可选；联动只编排，具体选择交给组件适配器。
- 后台创建 `runId`，定向派发并等待快慢及嵌套 frame；结果经可信 runtime 返回，超时与不可访问 frame 单独显示。页面伪造的 `postMessage` 不参与计数。
- 发布入口拒绝缺依赖、跳过必需用例、过滤后零用例及任意基准错漏配。真组件新增 Vue 2 Ant Design Vue 1 测试依赖，不随扩展发布。

源码备份位于系统临时目录 `resume-autofill-before-1.9.0.zip`。真实资料与简历库另有仓库外备份，升级时核对哈希。

## 验证与发布

最终发布门禁与真实站点读回结果在完成后登记。命令：`node tests/release.mjs`，全部通过后由 `python scripts/package.py` 生成运行包。
